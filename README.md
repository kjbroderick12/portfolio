# 🚀 My Portfolio

A modern, responsive portfolio website built with Next.js, TypeScript, and Tailwind CSS to showcase my projects, skills, and experience as a developer.

---

## 🛠 Tech Stack

- Next.js – React framework for building fast web apps
- TypeScript – Type-safe JavaScript
- Tailwind CSS (v4) – Utility-first CSS framework

---

## ✨ Features

- Clean, modern UI design
- Responsive layout for all devices
- Reusable component architecture
- Smooth navigation
- Project showcase (in progress)

## 🔧 Getting Started

### 1. Clone the repository

git clone https://github.com/YOUR_USERNAME/portfolio.git  
cd portfolio

### 2. Install dependencies

npm install

### 3. Run the development server

npm run dev

### 4. Open in your browser

http://localhost:3000
