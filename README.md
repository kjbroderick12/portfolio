# 🚀 Developer Portfolio

A modern, responsive portfolio website built with **Next.js, TypeScript, and Tailwind CSS** to showcase my work, technical skills, and experience as a software developer.

The portfolio highlights projects I've developed, the technologies I've worked with, and my approach to building practical, user-focused applications.

## 🛠 Tech Stack

- **Next.js** – React framework for building full-stack web applications
- **React** – Component-based UI development
- **TypeScript** – Type-safe JavaScript
- **Tailwind CSS v4** – Utility-first styling framework
- **Resend** – Email delivery for the contact form
- **Cloudflare Turnstile** – Spam and bot protection

## ✨ Features

- Responsive, mobile-first design
- Custom dark-themed interface
- Reusable component architecture
- Dedicated project pages with detailed descriptions and image galleries
- About page highlighting my background and development approach
- Services page outlining development services
- Multi-step contact form with input validation
- Email notifications through Resend
- Cloudflare Turnstile integration for contact form protection
- SEO metadata and Open Graph support
- Smooth navigation and subtle animations

## 📂 Project Structure

The application uses a feature-based architecture to organize pages, components, and related functionality.

```text
src/
├── app/                 # Next.js App Router and page routes
├── features/            # Feature-specific components and logic
│   ├── contact/
│   ├── home/
│   ├── projects/
│   └── ...
├── shared/              # Reusable components and shared utilities
└── ...
public/
└── images/              # Static images and project assets
```

## 🔧 Getting Started

### Prerequisites

- Node.js
- npm

### 1. Clone the repository

```bash
git clone https://github.com/kjbroderick12/portfolio.git
cd portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env.local` file in the project root and configure the environment variables required by the contact form and its integrations.

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Navigate to [http://localhost:3000](http://localhost:3000).
